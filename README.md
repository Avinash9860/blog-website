# BlogApplication

This project was generated with [Angular CLI](https://github.com/angular/angular-cli) version 9.1.1.

## Mobile preview (phone)

Run the app and get a link you can open on your phone:

```bash
npm run mobile
```

For live reload while developing:

```bash
npm run mobile -- --hot
```

See [scripts/README.md](scripts/README.md) for full details. You can copy `scripts/mobile-dev.sh` into any Angular, React, or Node.js project.

## Development server

Run `ng serve` for a dev server. Navigate to `http://localhost:4200/`. The app will automatically reload if you change any of the source files.

## Code scaffolding

Run `ng build` to build the project. The build artifacts will be stored in the `dist/` directory. Use the `--prod` flag for a production build.
